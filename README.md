# YATHVA – AI Fake News Detection System

🔗 Live Demo: https://yathva.vercel.app  
🔗 Backend API: https://yathva-1.onrender.com  

## 🚀 Features
- Fake News Detection using NLP
- Confidence Score
- Explainable AI (LIME)
- Word-level importance visualization

## 🧠 Tech Stack
- Python (Flask)
- React + TypeScript
- Scikit-learn, NLTK, LIME
- Vercel (Frontend), Render (Backend)

## ⚙️ How it Works
1. User inputs news text
2. Text is preprocessed (cleaning, stopword removal, lemmatization)
3. TF-IDF vectorization
4. Naive Bayes predicts REAL/FAKE
5. LIME explains prediction
